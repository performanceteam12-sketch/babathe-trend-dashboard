# 바바더닷컴 패션 트렌드 대시보드 — Context

**Last Updated**: 2026-07-24 (2차 업데이트: 사이드바 리디자인)

## 광고주/브랜드
- 바바더닷컴 (패션 브랜드, 자사)

## 목적
매주 소재(광고 크리에이티브) 기획 시 필요한 트렌드 리서치(레퍼런스, 키워드 쿼리량, 레이아웃/문안 트렌드)를 한 곳에서 확인할 수 있도록 대시보드화하여 소요 시간을 줄인다.

## 핵심 결정 사항
1. 네이버 데이터랩 쇼핑인사이트(패션의류>여성의류, 일간, 최근1개월) TOP10 인기검색어는 공식 API가 없어 저빈도(1일 1회) 웹 스크래핑으로 수집하기로 결정 (2026-07-24, 사용자 승인)
2. 더한섬닷컴/SSG(신세계몰)/W컨셉 앱 실시간 검색어는 API·크롤링 모두 불가능하다고 확인되어, 사용자가 앱을 직접 보고 대시보드에 반자동 입력하는 방식으로 결정 (2026-07-24, 사용자 승인)
3. 기술 스택은 기존 성과 마케팅 대시보드(`장서영 클로드 교육/dashboard/app.py`)와 동일하게 Streamlit 사용 (2026-07-24, 사용자 승인)

## 조사 근거 (2026-07-24 Explore agent 조사)
- 네이버 데이터랩 API(`openapi.naver.com/v1/datalab/shopping/...`)는 지정 키워드의 클릭 비율 추이만 반환, TOP10 랭킹 엔드포인트 없음
- 더한섬닷컴(thehandsome.com), SSG닷컴, W컨셉(wconcept.co.kr) 모두 모바일웹에 실시간 검색어 미노출, robots.txt가 화이트리스트 방식으로 일반 크롤러 차단

## 핵심 자료 경로
- 대시보드: `dashboard/app.py`
- 스크래퍼: `scraper/naver_datalab_scraper.py`
- 데이터: `data/naver_top10/`, `data/app_search/`

## 2차 리디자인 결정 사항 (2026-07-24)
- 상단 탭 대신 좌측 사이드바 3개 인덱스 구조로 변경: 이번 주 인기 검색어 / 광고 소재 레퍼런스 / 경쟁사 모니터링 (사용자 승인)
- 네이버 데이터랩 쿼리수(검색량)는 API 미제공이라 추가하지 않고 순위만 유지 (사용자 승인)
- 광고 소재 레퍼런스: 수동 큐레이션 갤러리(이미지/링크/태그 업로드) 방식으로 결정 (사용자 승인)
- 경쟁사 모니터링: 더한섬닷컴/신세계V/W컨셉/바바더닷컴 4개 브랜드, 브랜드별 브랜드검색 PC·MO + 메타 광고관리자 운영 소재 2종을 사용자가 직접 캡처해 업로드하는 반자동 방식 (사용자 승인, 경쟁사도 robots.txt 차단으로 자동 수집 불가)
- 디자인: 레퍼런스 이미지(Kumin 어드민 템플릿)보다 차분한 뉴트럴+단일 액센트(블루 #2563EB) 컬러로 재설계, taste-skill 색상/타이포 가이드 참고
